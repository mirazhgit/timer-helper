# Timer Helper

Простой секундомер прямо в редакторе VS Code с сохранением состояния между сессиями.

## Возможности

- ⏱️ Отображение секундомера в статус-баре (справа внизу)
- ▶️ Запуск, остановка и сброс через команды или меню
- 🖱️ Управление одним кликом мыши
- 📊 Формат времени: `00:00:00` (часы:минуты:секунды)
- 💾 **Сохранение состояния** - время не сбрасывается при перезапуске VS Code
- 🔄 **Автопродолжение** - если секундомер был запущен, он продолжит работать после перезапуска редактора

## Установка

### Способ 1: Через VS Code Marketplace

1. Откройте VS Code
2. Нажмите `Ctrl+Shift+X` (расширения)
3. Введите в поиске `Timer Helper`
4. Нажмите `Установить`

### Способ 2: Вручную (из .vsix файла)

```bash
code --install-extension timer-helper-1.0.5.vsix
```


## Как пользоваться

### Через палитру команд

1. Нажмите `Ctrl+Shift+P`
2. Введите одну из команд:
   - `Timer: Запустить секундомер`
   - `Timer: Остановить секундомер`
   - `Timer: Сбросить секундомер`
   - `Timer: Показать меню`

### Через клик мыши

1. Наведите курсор на секундомер в правом нижнем углу
2. Нажмите на него
3. Выберите нужное действие в появившемся меню

## Команды

| Команда | Действие |
|---------|----------|
| `Timer: Запустить секундомер` | Запускает таймер |
| `Timer: Остановить секундомер` | Останавливает таймер |
| `Timer: Сбросить секундомер` | Сбрасывает таймер на 00:00:00 |
| `Timer: Показать меню` | Открывает меню управления |

## Настройка горячих клавиш

Вы можете назначить свои горячие клавиши:

1. Нажмите `Ctrl+K Ctrl+S` (открыть настройку клавиш)
2. Найдите команды `timerHelper.start`, `timerHelper.stop`, `timerHelper.reset`, `timerHelper.showMenu`
3. Назначьте удобные сочетания (например `Ctrl+Shift+S` для запуска)

## Требования

- VS Code версии 1.74.0 или выше
- Нет внешних зависимостей

## ❗ Важно

Расширение автоматически сохраняет состояние секундомера:
- ✅ Время сохраняется при перезапуске VS Code
- ✅ Если секундомер был запущен, он продолжит работу после перезапуска
- ✅ Не нужно каждый раз сбрасывать и запускать заново
